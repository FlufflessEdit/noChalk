-----------------------------------------------------------------------------------------
Made by a teacher, for teachers.
I made it for myself and just want to share it.
Does not need any data from you and does not collect anything.

Hosted for free via github and the .ch was just the cheapest domain.
You save everything locally on your device.
If you want to run it locally, download the html file here

Works best with the Chrome Webbrowser!
